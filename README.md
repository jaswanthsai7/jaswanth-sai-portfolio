### Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/jaswanthsai7/jaswanth-sai-portfolio.git

# Navigate to the project directory
cd jaswanth-sai-portfolio

# Install dependencies
npm install

# Start the Vite local development server
npm run dev
```

The application will be running locally at `http://localhost:8081` (or next available port).

### Build for Production

```bash
npm run build
```
